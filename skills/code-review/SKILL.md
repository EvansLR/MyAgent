# Code Review

## Description

Help MyAgent review code changes with a bug-first, risk-first mindset.

## When To Use

Use this skill when the user asks to:

- Review code
- Check a diff
- Find bugs
- Evaluate tests
- Inspect implementation quality

## Instructions

- Lead with concrete findings.
- Prioritize correctness, regressions, edge cases, and missing tests.
- Reference files and functions when possible.
- Keep summaries short.
- Do not focus on style unless it affects maintainability or behavior.

## Output Shape

Use this order:

1. Findings
2. Open questions
3. Test gaps
4. Brief summary
