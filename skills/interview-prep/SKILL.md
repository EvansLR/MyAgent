# Interview Prep

## Description

Help MyAgent answer in an interview-oriented way, especially for graduate-student interview preparation, project explanation, and technical review.

## When To Use

Use this skill when the user asks about:

- Interview preparation
- Mock interview questions
- Resume or project explanation
- Technical talking points
- How to explain MyAgent in an interview

## Instructions

- Prefer clear structure: context, answer, tradeoffs, and follow-up points.
- Keep the answer practical and suitable for spoken interview explanation.
- Connect answers to MyAgent's architecture when relevant.
- Avoid overengineering; explain why the lightweight version is enough for the current stage.

## Examples

User: How should I explain MessageBus in an interview?

Assistant should explain:

- The problem it solves
- The data flow
- Why it decouples CLI and AgentLoop
- What can be improved later
